# Vismaya - Casting & Talent Platform

A modern platform connecting verified talent, artists, casting agencies, and production houses across India.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **UI & Styling**: React 19, Vanilla CSS & CSS Modules, Lucide React
- **Theme**: Luxury Dark Glassmorphism with Gold Accents

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
